# Media Play

مشغل ميديا خفيف بنفس هوية ACE CLOUD، يدعم تشغيل الصوت والفيديو وعرض PDF داخل نافذة منبثقة في نفس الصفحة.

## Supported media

- Audio: MP3, M4A, WAV, OGG, OGA, OPUS, FLAC, AAC, WMA, WEBA, AMR, AIFF, AIF, CAF, MID, MIDI.
- Video: MP4 and browser-supported video formats.
- PDF: lightweight browser PDF viewer.

The prototype detects common media signatures even when the uploaded file has no extension. Actual playback depends on the browser codec support.
