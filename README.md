# موج | MAWJ

مشغل وسائط شخصي باللغة العربية. أضف الملفات من جهازك، شغّل الصوت والفيديو داخل الصفحة، ورتّبها في قوائم تشغيل مستقلة للأغاني أو للفيديوهات.

## الاستخدام

افتح `index.html` مباشرة أو انشر المستودع كملف موقع ثابت على Vercel. اضغط **إضافة ملفات** أو اسحب الملفات إلى الصفحة. تظهر الملفات في مكتبتك، ويمكن إنشاء قوائم تشغيل من العمود الجانبي وإضافة عناصر المكتبة إليها. داخل القائمة، اسحب الملف لإعادة ترتيبه أو أزله منها دون حذفه من مكتبتك. يدعم المشغل التشغيل/الإيقاف، السابق/التالي، التقديم والتأخير، مستوى الصوت، التشغيل العشوائي، وتكرار الصف.

الملفات وبيانات القوائم تحفظ محليًا في IndexedDB داخل المتصفح، ولا تُرفع إلى خادم. ستظهر المكتبة على الجهاز والمتصفح نفسيهما؛ مسح بيانات الموقع قد يحذفها. يدعم التطبيق ملفات صوتية شائعة مثل MP3 وM4A وWAV وOGG وOPUS وFLAC وAAC وWMA وMIDI، وفيديو MP4 وWebM وMOV وM4V، وPDF للعرض. تعتمد الصيغ/الترميزات الفعلية على دعم المتصفح.

## ملفات المشروع

- `index.html` — التطبيق كاملًا بواجهة RTL متجاوبة.
- `assets/mawj/mawj-mark.svg` — علامة موج الصوتية الأصلية، بخلفية شفافة.
- `brand-spec.md` — مرجع ألوان وخطوط وهوية المنتج.
